# جورزیک فارسی

بازی روزانه‌ی جورزیک (شبیه Songless). جزئیات کامل پروژه توی [CLAUDE.md](./CLAUDE.md) هست.

## ساختار پوشه‌ها

- `client/` فرانت (React + Vite)
- `server/` بک‌اند (Node + Express)
- `tools/` اسکریپت‌های پایتون برای آماده‌سازی داده
- `data/` فایل‌های `songs.json` و `artists.json` (فقط‌خوندنی) + `data/audio/` (آهنگ‌های اصلی، توی گیت نیست)
- `clips/` کلیپ‌های ساخته‌شده از آهنگ‌ها (توی گیت نیست)

## اجرای لوکال

دو تا ترمینال جدا لازمه، یکی برای سرور و یکی برای کلاینت. برای پخش صدا، کلیپ‌های متناظر با `data/clip_map.json` رو در پوشه‌ی `clips/` بذار یا مسیرشون رو با `CLIPS_DIR` مشخص کن.

**سرور:**

```bash
cd server
npm install
npm run seed
npm run dev
```

برای دیتابیس تازه، `npm run seed` فهرست آهنگ‌ها رو وارد SQLite می‌کنه. اجرای دوباره‌ی سرور به seed دوباره نیاز نداره. سرور روی `http://localhost:3001` بالا میاد.

**کلاینت:**

```bash
cd client
npm install
npm run dev
```

کلاینت روی `http://localhost:5173` بالا میاد. صفحه باید نشون بده که سرور وصله.

## متغیرهای محیطی

- `CLIPS_DIR` مسیر پوشه‌ی کلیپ‌ها (پیش‌فرض `./clips`)
