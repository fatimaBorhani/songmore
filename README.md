# بازی حدس آهنگ فارسی

بازی روزانه‌ی حدس آهنگ (شبیه Songless). جزئیات کامل پروژه توی [CLAUDE.md](./CLAUDE.md) هست.

## ساختار پوشه‌ها

- `client/` فرانت (React + Vite)
- `server/` بک‌اند (Node + Express)
- `tools/` اسکریپت‌های پایتون برای آماده‌سازی داده
- `data/` فایل‌های `songs.json` و `artists.json` (فقط‌خوندنی) + `data/audio/` (آهنگ‌های اصلی، توی گیت نیست)
- `clips/` کلیپ‌های ساخته‌شده از آهنگ‌ها (توی گیت نیست)

## اجرای لوکال

دو تا ترمینال جدا لازمه، یکی برای سرور و یکی برای کلاینت.

**سرور:**

```bash
cd server
npm install
npm run dev
```

سرور روی `http://localhost:3001` بالا میاد.

**کلاینت:**

```bash
cd client
npm install
npm run dev
```

کلاینت روی `http://localhost:5173` بالا میاد. صفحه باید نشون بده که سرور وصله.

## متغیرهای محیطی

- `CLIPS_DIR` مسیر پوشه‌ی کلیپ‌ها (پیش‌فرض `./clips`)
